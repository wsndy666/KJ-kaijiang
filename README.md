# 🎉 扫码抽奖系统 ·「幸运时刻」

> **生产环境已部署**：`http://39.164.234.131:41080/`（服务器 `qx-001`，服务名 `lottery.service`，目录 `/opt/lottery-system`）
> 后台 `http://39.164.234.131:41080/admin`，后台密码见服务器 `/opt/lottery-system/DEPLOY-INFO.txt`
> 运维命令：`systemctl status|restart|stop lottery`，日志 `/opt/lottery-system/logs/stdout.log`

一套开箱即用的活动抽奖系统：用户扫码 → 看活动/奖品说明 → 填姓名手机号 → 进入开奖现场看倒计时与滚动名单 → 到点开奖。

- **零依赖**：只用 Node.js 原生模块，不需要 `npm install`
- **数据自控**：所有数据存在 `data/db.json`，随时可备份、可导出 Excel
- **移动端优化**：中国红 + 金的喜庆风格，专为手机竖屏设计
- **界面预览**：见 `预览截图/` 目录（10 张，含用户端与后台）

## 一、快速开始

### 1. 安装 Node.js
需要 Node.js 14 或更高版本（推荐 18/20/22）。下载：https://nodejs.org

### 2. 启动服务

**Windows**：双击 `启动服务.bat`

**Linux / macOS**：
```bash
cd lottery-system
node server.js
# 或者
sh start.sh
```

**换端口**（默认 8080）：
```bash
# Windows PowerShell
$env:PORT=9000; node server.js
# Linux
PORT=9000 node server.js
```

启动后终端会打印两个地址：

| 用途 | 地址 |
|---|---|
| 用户参与页（二维码指向它） | `http://localhost:8080/` |
| 管理后台 | `http://localhost:8080/admin` |

默认后台密码：**admin123**（登录后请立即修改）

### 3. 想先看看效果？灌一批演示数据

系统默认是**干净状态**（没有参与者、没设开奖时间）。想快速预览，跑一条命令即可：

```bash
node tools/seed-demo.js          # 20 位演示参与者，开奖时间 = 当前 +10 分钟
node tools/seed-demo.js 50 5     # 50 位参与者，开奖时间 = 当前 +5 分钟
node tools/seed-demo.js --clear  # 清空演示数据（活动/奖品配置保留）
```

灌完后打开 `http://localhost:8080/?preview=1` 就能看到倒计时和滚动名单。
**活动正式开始前记得执行一次 `--clear` 清干净。**

## 二、部署到服务器（让手机能扫码访问）

用户手机上要能打开，服务器地址必须是**手机能访问到的地址**：

1. 把整个 `lottery-system` 文件夹上传到服务器（如 `/opt/lottery-system`）
2. 启动服务：
   ```bash
   cd /opt/lottery-system
   nohup node server.js > lottery.log 2>&1 &
   ```
3. 开放服务器防火墙的 8080 端口
4. 后台 → **二维码** 页 → 把「活动访问地址」改成 `http://你的公网IP:8080/` → 点「生成二维码」

**更推荐的做法**：用 Nginx 反代到 80 端口 + 域名，这样链接更短更好看：

```nginx
server {
    listen 80;
    server_name huodong.yourdomain.com;
    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

> 想让服务开机自启 / 挂了自动重启，可以用 `pm2`：`pm2 start server.js --name lottery && pm2 save`

## 三、后台使用说明

进入 `http://你的地址/admin`，输入密码登录。共 5 个标签页：

### 1️⃣ 活动设置
- 活动标题 / 副标题 / 活动说明（支持换行）
- 奖品名称、**中奖名额（共几名）**、奖品图片地址（选填）
- **奖品高亮标签**：奖品页顶部的小标签，如「75% 超高水效 · 超越国家一级水效标准」
- **奖品简介**：参与页弹层里显示的一段话，别太长
- **核心卖点**：一行一条，展示在独立奖品页（自动编号卡片）
- **产品参数**：一行一条，格式 `参数名|参数值`，展示在奖品页的参数表
- 奖品图片可以填网络图片地址，也可以把图片放到 `public/img/` 后填 `img/文件名.jpg`
- 当前已配置：**物联家用直饮机 T941**，图片为 `img/prize-t941-full.jpg`（1279×1991 竖版海报）
  - 参与页的小图会自动裁切到产品区域，点小图或「查看完整奖品详情 ›」进入**独立奖品页**
  - 想换图：把新图放进 `public/img/`，在后台「奖品图片地址」改成 `img/新文件名.jpg` 即可
  - 图片建议：正方形或接近正方形的产品图，小图展示效果最好
- 点「预览奖品页」可直接在新窗口查看效果

### 2️⃣ 开奖设置
**开奖方式**（二选一）：

| 模式 | 行为 |
|---|---|
| **固定时间开奖** | 到达设定的开奖时间后，系统**自动开奖**并公布名单，无需人工操作 |
| **临时开奖** | 倒计时到 0 后**不自动开**，页面提示「等待主持人开启」，由你在后台点「立即开奖」 |

> **关于「固定时间开奖」的一个重要行为**：同一个开奖时间**只会自动开一次**。
> 也就是说，自动开完之后你点「重置开奖」，**不会**因为"时间已经过去"而被系统立刻重开一遍——
> 要重新抽就点「立即开奖」；想重新启用自动开奖，把开奖时间改成一个**新的**时间即可。
>
> **改开奖时间 = 重新安排一轮**：把开奖时间改成一个**未来的**新时间并保存，系统会自动清空上一轮的
> 中奖结果、回到「未开奖」，扫码的人重新看到倒计时（保存成功后会有提示）。
>
> 另外，到点时如果还没有人参与，系统会跳过不产生空的中奖记录，并在有人参与后补开。
>
> ⚠️ **测试彩排时最容易踩的坑**：开奖时间一旦过去，系统就会自动开奖，之后扫码进来的人看到的
> 就是「已揭晓」——这不是坏了，是时间到了。想再测一遍，把开奖时间改成几分钟后再保存即可。

- **开奖时间**：两种模式都用它来做页面倒计时
- **规则开关**：
  - 一个手机号只能参与一次（可关，关掉后同一手机号可重复报名）
  - 一人最多中一个奖
  - 开奖后仍允许报名 / 开启滚动动画
- **后台密码**：留空则不修改

### 3️⃣ 开奖操作（在开奖设置页底部）
- **立即开奖**：从当前参与者中随机抽出设定名额的中奖用户，立即在参与页公布
- **重置开奖**：清空中奖名单、状态回到「未开奖」，**参与者保留**（用于重新抽一次）
- **清空全部数据**：删除所有参与者 + 中奖记录（需二次确认）

### 4️⃣ 参与名单
- 实时查看所有参与者，支持搜索姓名/手机号
- 可手动添加参与者、删除某条记录
- **导出 Excel(CSV)**：带 BOM，Excel 直接打开不乱码

### 5️⃣ 二维码
- 显示/复制活动链接，一键生成二维码图片（右键保存即可印刷）
- 如果电脑打不开在线二维码服务，把链接复制到任意二维码工具（如草料二维码）生成同样可用

## 四、用户体验流程

1. **扫码进入** → 弹出活动说明 + 奖品说明 → 填姓名、手机号 → 点「提交并进入开奖现场」
2. **看奖品**：点奖品小图或「🎁 查看奖品详情 ›」→ 进入**独立奖品页** `/prize`
   - 大图主视觉（带金色光晕）、奖品名、高亮标签、中奖名额
   - 核心卖点：带编号的卡片列表
   - 产品参数：规整的对照表
   - 点大图可看原图；底部固定按钮「我要参与抽奖」回到参与页
   - 这个页面也可以单独投屏/打印做奖品介绍
3. **进入开奖现场**：
   - **上半部分**：开奖方式标签、开奖时间、倒计时（最后 10 秒会跳动闪烁）
     - 中奖名单区：开奖前滚动显示，开奖时加速滚动 → 逐个定格并高亮中奖者，同时撒花
   - **下半部分**：参与用户手机号（脱敏 `138****1111`）无限向上滚动，显示实时参与人数
4. **开奖后**：中奖名单带金色高亮固定展示，倒计时变为「本轮已开奖」
5. 已经参与过的用户再次扫码，会直接进入开奖现场（自动识别），不会重复提交

## 八、常见问题

**Q：手机上打不开？**
A：检查三点 —— ① 地址是不是手机能访问的（别用 `localhost`，要用局域网 IP 或公网 IP/域名）；② 服务器防火墙/安全组有没有放行端口；③ 电脑和手机是不是在同一个网络（局域网场景）。

**Q：二维码显示不出来？**
A：生成二维码需要一个在线服务，如果这台电脑没有外网就生成不了。直接复制链接到草料二维码等工具生成即可，效果一样。

**Q：中途想改奖品数量怎么办？**
A：改完保存即可。如果已经开过奖，想按新名额重抽，先在「开奖设置 → 重置开奖」，再点「立即开奖」。

**Q：活动已经自动开奖了，还能再加人吗？**
A：「开奖后仍允许报名」开关决定。开启时新人可以继续报名，但不会进入本轮中奖名单；想让新人参与，需重置后重新开奖。

**Q：参与人数很多会卡吗？**
A：参与页只展示脱敏手机号和总数，服务端按下发顺序最多取 200 条用于滚动效果，几千人量级没问题。

**Q：想换个风格（比如春节主题）怎么改？**
A：改 `public/css/festive.css` 顶部的 `:root` 变量即可（`--gold` 金色、`--red-main` 主红、`--cream-*` 文字色）。背景灯笼/金粒的图形在 `public/js/festive.js` 里，注释已标明每段是什么。

## 九、接口一览（供二开参考）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/state` | 公开状态：活动信息、开奖时间、是否已开奖、中奖名单（脱敏）、参与人数 |
| POST | `/api/join` | 报名 `{name, phone}` |
| POST | `/api/admin/login` | 后台登录 `{password}` → `{token}` |
| GET | `/api/admin/data` | 后台全量数据（需 `x-admin-token`） |
| POST | `/api/admin/config` | 保存配置 |
| POST | `/api/admin/draw` | 立即开奖 |
| POST | `/api/admin/reset` | 重置开奖状态 |
| POST | `/api/admin/clear` | 清空数据 `{confirm:"CLEAR"}` |
| POST | `/api/admin/participant/add` | 手动添加参与者 |
| POST | `/api/admin/participant/delete` | 删除参与者 `{id}` |
| GET | `/api/admin/export` | 导出 CSV |
